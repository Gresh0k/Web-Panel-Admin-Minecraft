# Web-Panel-Admin-Minecraft

> Удобная веб-панель для администрирования сервера Minecraft

## 📖 Описание

Это pet-проект, представляющий собой веб-панель для удаленного администрирования и управления сервером Minecraft. Панель предоставляет интуитивно понятный графический интерфейс, который позволяет управлять сервером без необходимости постоянного использования SSH или прямой работы с консолью хоста.

## ✨ Возможности

*(Примечание: вы можете дополнить этот список в зависимости от реализованных функций)*

- 🚀 **Управление сервером**: Запуск, остановка и перезагрузка сервера в один клик.
- 💻 **Консоль в реальном времени**: Просмотр логов и отправка команд в консоль сервера прямо из браузера.
- 👥 **Управление игроками**: Просмотр списка онлайн-игроков, кик, бан и управление правами.
- ⚙️ **Редактирование конфигураций**: Удобное редактирование файлов `server.properties` и других конфигов через веб-интерфейс.
- 🐳 **Docker-поддержка**: Простая и быстрая установка и развертывание благодаря контейнеризации.

## 🛠 Технологический стек

Проект разработан с использованием следующих технологий:

- **Frontend**: HTML (~47%), CSS (~11%), JavaScript (~17%)
- **Backend**: Python (~25%)
- **Инфраструктура**: Docker (~0.4%)

## 🚀 Установка и запуск

### Вариант 1: Использование Docker (Рекомендуемый)

1. Убедитесь, что у вас установлены [Docker](https://www.docker.com/) и [Docker Compose](https://docs.docker.com/compose/).
2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Gresh0k/Web-Panel-Admin-Minecraft.git
   cd Web-Panel-Admin-Minecraft
   ```
3. Соберите и запустите контейнер:
   ```bash
   docker build -t mc-admin-panel .
   docker run -d -p 8000:8000 --name mc-panel mc-admin-panel
   ```
   *(Если в проекте есть `docker-compose.yml`, используйте `docker-compose up -d`)*
4. Откройте браузер и перейдите по адресу: `http://localhost:8000` (порт может отличаться в зависимости от ваших настроек).

### Вариант 2: Ручной запуск (для разработки)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Gresh0k/Web-Panel-Admin-Minecraft.git
   cd Web-Panel-Admin-Minecraft
   ```
2. Установите зависимости Python (рекомендуется использовать виртуальное окружение):
   ```bash
   python -m venv venv
   source venv/bin/activate  # Для Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Запустите сервер приложения:
   ```bash
   python main.py  # Замените на app.py или другое имя основного файла, если необходимо
   ```
4. Откройте `http://localhost:8000` в вашем браузере.
